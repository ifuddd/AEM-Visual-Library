# Lottie Animations

This folder contains Lottie animation files used throughout the AEM Visual Library portal.

## Required Animations

Download the following animations from [lottiefiles.com](https://lottiefiles.com/free-animations/interactivity):

1. **success.json** - Success confirmation animation
   - Used for: Save button success state
   - Recommended: Green checkmark or success icon
   - Duration: ~2 seconds
   - Loop: No

2. **upload-success.json** - Upload success animation
   - Used for: Thumbnail upload confirmation
   - Recommended: Upload icon with checkmark
   - Duration: ~2 seconds
   - Loop: No

3. **loading.json** - Loading animation
   - Used for: Page loading states (catalog, detail page)
   - Recommended: Spinner, dots, or pulse animation
   - Duration: ~1-2 seconds
   - Loop: Yes

## How to Download

1. Visit https://lottiefiles.com/free-animations/interactivity
2. Search for animations matching the descriptions above
3. Download as JSON (Lottie JSON format)
4. Rename the files to match the names above
5. Place them in this directory

## Tips

- Keep file sizes small (< 50KB per file)
- Choose animations with simple, clean designs
- Ensure animations work well with both light backgrounds
- Test animations in the app to verify they feel snappy and professional
